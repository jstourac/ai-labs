# Agents Directory

This directory contains specialized agent configurations for Claude Code.

## How to Add an Agent

Create a new directory for your agent:

```
agents/
└── your-agent-name/
    ├── agent.md       # Agent definition (required)
    ├── tools.json     # Tool configuration (optional)
    ├── knowledge/     # Knowledge base (optional)
    └── README.md      # Documentation (recommended)
```

See [AGENTS.md](../AGENTS.md) for detailed instructions on creating agents.
