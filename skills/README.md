# Skills Directory

This directory contains individual skill definitions for Claude Code.

## How to Add a Skill

Create a new directory for your skill:

```
skills/
└── your-skill-name/
    ├── skill.md       # Skill definition (required)
    ├── config.json    # Configuration (optional)
    └── README.md      # Documentation (recommended)
```

See [AGENT.md](../AGENT.md) for detailed instructions on creating skills.
